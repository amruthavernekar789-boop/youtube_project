# YouTube Accessing and Material Distribution

## About the Project
YouTube Accessing and Material Distribution is an academic web application developed to provide users with a platform to upload, access, and interact with educational video content.

The project includes separate functionalities for users and administrators.

## Features

### User
- User registration and login
- Like and dislike videos
- Comment on videos

### Admin
- Upload videos with titles, descriptions, and thumbnails
- Manage uploaded content
- Monitor likes and comments
- Delete videos and comments

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- phpMyAdmin
